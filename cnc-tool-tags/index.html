From library to the holder

AirShop prints the labels. Fold them onto Edgeview tags so the holder on the floor matches the record.

  1. 1. Add tools Keep the library in AirShop. Import the list you already have, or add a single tool and fill the specs.
  2. 2. Print labels Queue tools, then print on a Dymo LabelWriter. Standard stock is 1 × 2.125 in. TTS uses 1 × 1.5 in.
  3. 3. Label the tags Peel the thermal label and fold it over the Edgeview lip so gauge length and SKU stay readable from the edge.
  4. 4. Load tools and towers Tag stays on the holder in a drawer or on the bench. When the tool is in the spindle or carousel, the tag lives in the Tool Tag Tower.
