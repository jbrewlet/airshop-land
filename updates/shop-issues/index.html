Track shop issues without leaving AirShop

Report broken equipment, assign it to a teammate, and track it to done from the same dashboard where you manage inventory and quotes.

Every shop has a running list of things that need fixing: a broken label printer, a bin that needs relocating, or a process that could be smoother. Until now, that list lived in texts, sticky notes, or a separate tool. Now it lives in AirShop as Issues.

Report an issue in seconds. Give it a title, then optionally add a description, photos, an assignee, and a priority. You can report it from your dashboard or straight from the inventory item it's about. AirShop links the item automatically.

Assign it, prioritize it, track it to done

Add one or more teammates as assignees so everyone knows who owns what, then move the issue through Open → In Progress → Resolved → Done as work happens. Link it to the inventory item, asset, or SOP it's about so context stays attached.

Never lose track of a deadline

Set an optional due date. Overdue or soon-due issues surface first on your dashboard's new Shop Issues card, so nothing quietly slips.

Find anything, fast

Search for an issue by title, description, or linked subject right from the AirShop search bar. Search includes closed issues, so nothing gets lost once it's resolved.
